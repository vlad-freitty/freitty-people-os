# Фаза 4 — Дашборди й полірування: план і рішення

21.10.2026 · PRD розділи 7, 8 · статус: **виконується без окремого погодження** (див. фаза 2).

## 1. Обсяг і критерії готовності

Повні дашборди для всіх ролей за PRD 7, мобільна адаптивність, ліцензії й вартість (є з фази 1).
**Готово, коли:** усі сценарії з розділу 7 працюють на телефоні — перевіряю в браузері на ширині 375 px:
дашборд, «Мої задачі», картка заявки з дією по кроку, нова заявка, календар, профіль із балансом, зміни, оплати.

## 2. Що додається на дашборд (кожен бачить у межах своїх прав)

| Блок | Хто бачить | Звідки |
|---|---|---|
| Мої заявки (в роботі) | усі з профілем | заявки, де я ініціатор |
| Мої зміни (цей і наступний тиждень) й останні оплати | усі з профілем | Shift, Payment (`employees.view_sensitive` self) |
| Заявки відділу за статусами | `requests.view` departments / all | Request |
| Документи, що спливають за 30 днів | `employees.view_sensitive` departments / all | Document.valid_to |
| Headcount по компаніях і відділах | `employees.view` departments / all | Employee |
| Оплати за статусами (відкриті періоди) | `payments.manage` | Payment |
| Премії до виплати | `payments.manage` | Bonus approved / included |

Блоки, що вже є: задачі, прострочені кроки, кроки без виконавця, випробувальні 30/60/90, баланс, свята й дні народження,
хто відсутній, ліцензії.

## 3. Мобільна адаптивність

1. Шапка: на вузьких екранах навігація ховається в меню-кнопку замість горизонтальної прокрутки з 15 посилань.
2. Календар: на телефоні — список подій по днях (agenda) замість сітки 7×6.
3. Таблиці лишаються з горизонтальною прокруткою; на телефоні другорядні колонки ховаються.
4. Локалізовані сторінки 404 і помилки, індикатор завантаження між сторінками.
